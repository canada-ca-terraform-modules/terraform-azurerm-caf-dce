# Copilot / Claude instructions — terraform-azurerm-caf-dce

This module wraps a single resource: `azurerm_monitor_data_collection_endpoint`. It has no
sibling resources (no private endpoint, no secret/backup/autoshutdown support) because the
underlying Azure resource needs none of those.

## Commands

```bash
terraform init -backend=false
terraform fmt -recursive
terraform validate
terraform test
```

To plan against the ESLZ example (requires real Azure resource IDs, not just mocks):

```bash
cd ESLZ && terraform init && terraform plan -var-file=DataCollectionEndpoint.tfvars
```

## Naming convention

`{env4}-{group}-{project}-{userDefinedString}-dce`, lowercased and stripped of any character not
matching `[0-9a-z-]`, truncated to 64 chars. Implemented in [name.tf](name.tf); resource
group name resolution (accepts either a `resource_groups` map key or a full resource ID) is
in [locals.tf](locals.tf).

## Design patterns present in this module

- Every optional top-level argument uses `try(var.dce.<attr>, <registry_default>)`.
- `public_network_access_enabled` defaults to `true` to match the registry default.
- `tags = merge(var.tags, try(var.dce.tags, {}))` — never invent tags, always merge the
  caller's.
- This resource has no nested blocks, so no `dynamic` blocks are needed — keep it that way
  unless a future provider version adds one.

## Agent guidance checklist

- Read `variables.tf` → `locals.tf` → the target file before editing.
- Check `ESLZ/DataCollectionEndpoint.tf` before changing this module's variable interface —
  it's copied verbatim into consuming ESLZ blueprints and must stay in sync.
- Check naming side-effects before changing how `env`/`group`/`project`/`userDefinedString`
  are combined — any change here changes every existing endpoint's Azure resource name.
- Keep edits outside the `<!-- BEGIN_TF_DOCS -->` / `<!-- END_TF_DOCS -->` markers in
  `README.md` — that section is regenerated by CI.
- Run `terraform fmt -recursive` after any `.tf` edit.
- Add a new `run` block to `tests/dce.tftest.hcl` for any new optional argument/block.
